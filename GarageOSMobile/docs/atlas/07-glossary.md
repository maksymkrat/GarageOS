# 07 · Глосарій

Ідентифікатори в коді — англійські, інтерфейс і помилки — українські. Ця
сторінка тримає відповідність між ними, щоб те саме поняття не отримало двох
назв.

## Доменні сутності

| Код | Українською | Що це |
|-----|-------------|-------|
| `Car` | авто (клієнтське) | картка авто в картотеці СТО: номер, власник, телефон, пробіг, статус, борг. Живе довго, між візитами |
| `Order` | наряд, замовлення-наряд | один візит авто: скарга, роботи, деталі, оплата. Належить авто через `carId` |
| `OrderWork` | робота | рядок наряду: назва роботи та її ціна |
| `OrderPart` | деталь | рядок наряду: назва, кількість, закупівельна (`buy`) і продажна (`sell`) ціна |
| `Reminder` | нагадування | що треба обслужити на конкретному авто і чи вже прострочено |
| `MyVehicle` | моя техніка, одиниця техніки | власна техніка в особистому режимі: авто, мото, будь-яка обслуговувана машина. **Не** те саме, що `Car` |
| `LogEntry` | запис журналу | одне виконане обслуговування своєї техніки: дата, пробіг, що зроблено, витрати |

## Read-моделі

| Код | Українською | Що це |
|-----|-------------|-------|
| `CarDetail` | картка авто | авто + усі його наряди + скільки ще авто на тому ж телефоні |
| `OrderDetail` | картка наряду | наряд разом з його авто |
| `FinanceOverview` | фінансовий зріз | показники за період + боржники + сумарний борг |
| `FinanceStats` | показники | виторг (`earned`), частка робіт (`works`), частка деталей (`parts`), кількість візитів (`visits`) |
| `ReminderItem` | нагадування (для екрана) | нагадування, вже склеєне з даними авто |
| `WorkBoardRow` | рядок дошки робіт | авто + скарга з відкритого наряду + дні очікування |

## Статуси та перелічення

| Значення | Українською | Сенс |
|----------|-------------|------|
| `in_work` | у роботі | авто в цеху, робота йде |
| `waiting_part` | чекає деталь | робота зупинена до приходу запчастини |
| `ready` | готове | роботи завершені, авто можна віддавати |
| `has_debt` | є борг | за авто не розрахувалися |
| `week` / `month` / `year` | тиждень / місяць / рік | період фінансового зрізу |
| `oil` | олива | тип запису журналу |
| `brakes` | гальма | тип запису журналу |
| `tires` | шини | тип запису журналу |
| `filter` | фільтр | тип запису журналу |
| `other` | інше | тип запису журналу |

## Поняття архітектури

| Термін | Що означає в цьому проєкті |
|--------|---------------------------|
| **Атлас** | `GarageOSMobile/docs/atlas/` — карта системи: межі, домени, дані, API, рішення |
| **Контракт** | `GarageOSMobile/src/types/domain.ts` + `GarageOSMobile/src/api/*.ts`. Джерело істини для форми даних ([ADR-0002](adr/0002-client-contract-source-of-truth.md)) |
| **Шов транспорту** | функція `request()` — єдина точка, де клієнт вирішує, звідки беруться дані: мок чи HTTP |
| **Сервісний режим** | `src/app/(service)/` — екрани для СТО: дошка робіт, картотека, гроші, нагадування |
| **Особистий режим** | `src/app/personal/` — свій гараж: власна техніка та її журнал |
| **Дошка робіт** | екран `work.tsx`: активні авто, згруповані за статусом. Збирається на клієнті, не має свого ендпойнта |

## Терміни, яких свідомо немає

Щоб їх випадково не ввели: **пост** (робоче місце), **зміна**, **механік** як
сутність, **запис на час** (appointment), **склад** і **залишок**,
**постачальник**, **рахунок** (invoice) як окремий документ, **роль** і
**користувач**. Нинішня модель обходиться без них; якщо котресь стане
потрібним — спершу сюди, потім у код.
