# ADR-0003 · Монорепозиторій з `apps/mobile` та `apps/api`

**Статус:** Accepted · **Дата:** 2026-10-09

## Контекст

Застосунок і бекенд починалися як окремі папки в різних деревах:
`D:\projects\react\GarageOS` (Expo, під git) і `D:\projects\net\GarageOS`
(.NET, без git взагалі). Контракт між ними тісний: згідно з
[ADR-0002](0002-client-contract-source-of-truth.md) зміна форми даних зачіпає
обидві сторони одночасно.

## Рішення

Один репозиторій:

```
GarageOS/
  apps/mobile/   Expo / React Native
  apps/api/      ASP.NET Core 9
  docs/atlas/    атлас архітектури
  CLAUDE.md      спільні правила
```

Корінь git — колишній репозиторій мобільного застосунку, його історія
збережена. `.claude/`, `.mcp.json`, `.vscode/`, `LICENSE` підняті на корінь,
щоб діяти на обидва яруси. `.gitignore` розділений: корневий закриває
артефакти .NET та IDE, `apps/mobile/.gitignore` — Node та Expo.

Поділ `apps/api` за фічами (`Features/Cars/`, `Features/Orders/`), а не за
типами, щоб межі модулів сервера збігалися з межами модулів у
`apps/mobile/src/api/`.

## Альтернативи

**Два репозиторії** — незалежні релізи й права доступу. Відкинуто: один
розробник, спільний цикл, а зміна контракту вимагала б двох скоординованих
PR замість одного коміту.

**Папка-контейнер із двома репозиторіями** — одна робоча директорія, але
окремі історії. Відкинуто: дає найгірше з двох світів — ні атомарності
коміту, ні справжньої незалежності.

## Наслідки

**Добре:** зміна контракту — один атомарний коміт (тип клієнта + DTO сервера
+ сторінка атласу); один набір дозволів і один `CLAUDE.md`; атлас описує
систему цілком, а не один ярус.

**Ціна:** CI доведеться робити з фільтрами за шляхами, щоб збірка .NET не
запускалася на правку екрана. До появи CI це не коштує нічого.

## Примітка про виконання

Папки переносилися вмістом, а не перейменуванням каталогу: редактори тримали
старі каталоги як робочі (`Device or resource busy`). Тому порожні оболонки
`D:\projects\react\GarageOS` і `D:\projects\net\GarageOS` лишилися на диску й
видаляються вручну після закриття VS Code та Rider.
