# ADR-0002 · Контракт клієнта — джерело істини для API

**Статус:** Accepted · **Дата:** 2026-10-09

## Контекст

Мобільний застосунок написаний першим і вже працює: `src/types/domain.ts`
визначає доменні типи, `src/api/*.ts` — операції, `src/api/mock/` їх реалізує
зі штучною латентністю та помилками. Екрани, ключі кешу та read-моделі
(`CarDetail`, `FinanceOverview`, `WorkBoardRow`) побудовані на цих формах.

Бекенд — порожній шаблон ASP.NET Core. Постає питання, хто кому диктує форму
даних.

## Рішення

**Клієнтський контракт первинний.** `GarageOSWeb` реалізує те, що вже оголошено
в `GarageOSMobile/src/api/*.ts`, включно з назвами шляхів, вкладеністю
read-моделей і текстами помилок українською.

Зміна форми даних починається з `domain.ts` і `src/api/*`, і лише потім
доходить до сервера — у **тому самому коміті**, разом зі сторінкою атласу.

Сервер не має права «покращити» форму відповіді односторонньо: наприклад,
віддати плоске авто замість `{ car, orders, sameOwnerCount }` або ISO-дати
замість людських міток. Такі зміни можливі, але як правка контракту.

## Альтернативи

**Сервер диктує, клієнт підлаштовується** — природніше для .NET-команди і дає
чистіші DTO. Відкинуто: переписувати працюючі екрани й шар запитів заради
естетики DTO дорожче, ніж реалізувати наявну форму.

**Кодогенерація з OpenAPI** — сервер як джерело, типи генеруються в клієнт.
Відкинуто **на зараз**: контракт ще рухається, а генерація зафіксувала б
напрямок залежності у протилежний бік. Варте перегляду, коли модель
стабілізується.

**Спільна схема окремо від обох** (напр. TypeSpec) — третє джерело істини.
Відкинуто як передчасне для двох ярусів і одного розробника.

## Наслідки

**Добре:** перехід з моків на реальний API — заміна реалізації `request()`
в одному файлі, без правок екранів. Клієнт лишається працездатним на кожному
кроці.

**Ціна:** сервер успадковує рішення, зроблені для UI — дати-рядки, гроші як
`number`, вкладені `works`/`parts` без `id`, відсутність версіонування шляхів.
Усі ці компроміси перелічені в
[03-data-model.md](../03-data-model.md#відкриті-питання-моделі) і
[04-api-surface.md](../04-api-surface.md#конвенції) — не забуті, а свідомо
прийняті.

**Ризик:** розбіжність клієнта й сервера виявиться в рантаймі. Мітигація —
контрактні тести ([05-cross-cutting.md](../05-cross-cutting.md#тести)).
