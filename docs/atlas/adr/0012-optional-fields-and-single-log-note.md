# ADR-0012 · Рік і пробіг авто опційні, запис журналу — один опис

**Статус:** Accepted · **Дата:** 2026-10-14 · **Ухвалено:** 2026-10-14

## Контекст

Дві незалежні проблеми, обидві про те, що модель змушувала вигадувати дані.

**Рік і пробіг авто були обов'язкові.** `CreateCarInput` дозволяє їх не
передавати — `year?`, `mileage?`, — але колонки були `NOT NULL`, тож
`CarService` підставляв:

```csharp
Year = request.Year ?? today.Year,
Mileage = request.Mileage ?? 0,
```

Авто без відомого року ставало «цьогорічним», без пробігу — «з нульовим
пробігом». Обидва значення потім нічим не відрізнити від справжніх. Нульовий
пробіг ще й читався нагадуванням за пробігом як «ще далеко до строку», хоча
правильна відповідь — «невідомо».

**Запис журналу ТО мав і заголовок, і нотатку.** `Title` обов'язковий, `Note`
опційна. На практиці межа між ними не визначена: «Масло + масляний фільтр» і
«Mazda Dexelia 0W-20, 4.5 л» — це одне речення, розрізане навпіл, і власник
техніки щоразу вирішував, у яку половину покласти кожне слово. З семи записів
демо-даних два мали `note = NULL` — просто бо нічого не лишалося додати.

Окремо запис зберігав `Mileage` — пробіг на момент робіт. Поле існувало з
першої міграції й показувалося в одному рядку інтерфейсу.

## Рішення

**`cars.year` і `cars.mileage` — nullable.** Дефолти з `CarService` прибрані:
що передали, те й записано, включно з «не передали». Нагадування за пробігом
при невідомому пробігу **не вважається простроченим** —
`Reminder.IsOverdue` перевіряє наявність значення, а не порівнює з нулем.

**У запису журналу лишається один опис — `Note`, обов'язковий.** `Title`
видалено, `Mileage` видалено. Запис тепер: дата, що зроблено, скільки
коштувало, тип.

Поле лишилося з назвою `Note`, хоч воно вже не «нотатка», а єдиний опис.
Перейменування на щось точніше (`Description`, `What`) — окрема зміна
контракту, і робити її варто разом, а не слідом; поки назва неточна свідомо.

Опційне в контракті означає **відсутнє**, не `null`: `Program.cs` налаштований
на `JsonIgnoreCondition.WhenWritingNull`, тож авто без року не має ключа `year`
у відповіді зовсім. Перевірено: створене без року й пробігу авто повертає
`{id, plate, make, model, owner, phone, status, debt, lastVisit}`.

## Міграція

`20261014152556_LogEntryNoteOnly`, **дописана руками двічі**.

Скаффолд спершу видаляв `title`, а потім робив `note` обов'язковою з
`defaultValue: ""`. Це втрата двічі: текст заголовка зникає, а два записи з
порожньою нотаткою стають порожніми рядками — запис, який не каже нічого.

У робочій версії заголовок **зливається** з нотаткою до видалення:

```sql
UPDATE log_entries
SET note = LEFT(CASE WHEN note IS NULL OR note = '' THEN title
                     ELSE title || ' — ' || note END, 1000);
```

`LEFT(..., 1000)` тому, що дві колонки разом (200 + 1000) не влазять у ту, яка
мусить їх умістити. Результат на демо-даних:

```
Масло + масляний фільтр — Mazda Dexelia 0W-20, 4.5 л
Салонний фільтр
```

Пробіг запису не відновлюваний і просто видалений. `Down` повертає колонки, але
не розрізає опис назад: правила, які слова були заголовком, не існує.

Для `cars` це розширення (`NOT NULL` → nullable), тож усі значення збереглися.

## Наслідки

**Добре.** Невідоме більше не записується як значення. «Пробіг невідомий» і
«пробіг 0» — різні стани, і нагадування їх розрізняє. Журнал ТО не змушує
ділити одну думку на дві частини.

**Ціна — опційність доїхала до екранів.** Там, де поля могло не бути, інтерфейс
мусить це передбачати:

- картка авто не показує рядок «Пробіг», якщо пробігу немає — замість «0 км»;
- заголовок картки не лишає коми без року;
- у списку авто рік зникає разом із пробілом перед ним.

Це знайшов не я, а `tsc`: опційні поля в контракті зламали компіляцію в чотирьох
місцях, і кожне довелося вирішити свідомо.

**Втрачено.** Пробіг на момент кожних робіт у журналі ТО. Якщо він знадобиться
(«коли міняли масло на якому пробігу»), це нова колонка й нова міграція —
старих значень уже немає.

**Назва `Note` неточна.** Поле несе весь опис, а зветься нотаткою. Виправляється
перейменуванням у контракті, БД і клієнті — одним комітом, коли по це дійде
черга.
